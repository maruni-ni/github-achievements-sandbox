# GitHub workflow sandbox

A personal sandbox for practicing GitHub issues, branches, and pull requests.

This repository contains only practice documentation. It is separate from application and coursework repositories.

## Exercises

1. Create and close an issue after verifying repository initialization.
2. Add an issue workflow guide through a pull request.
3. Add a pull request workflow guide through a second pull request.

The exercises also test GitHub profile achievement eligibility. Awarding and display are controlled by GitHub.
